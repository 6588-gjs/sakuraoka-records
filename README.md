# 旧樱丘高中记录室残存档案

> Sakuraoka High School: Records Room Remaining Files  
> 互动叙事解谜游戏 · 竖屏 H5 · V1.1.0

旧校拆除前夜，你潜入被抹去的档案室，用证据拼出姐姐消失的真相。

1998 年的日式校园官网还停在最后一次更新：修正液涂掉的第 31 号、凌晨的换锁记录、旧校报里被写成「转校」的死亡。表网页给学校看，里网页只写事实——但每找到一件证据，你的名字就会被削去一点。

## 在线游玩

**<https://6588-gjs.github.io/sakuraoka-records/>**

建议使用竖屏手机浏览器；桌面浏览器也可游玩。首次进入可选择语言（简体中文 / 日本語 / 双语，默认双语）。

## 玩法

- 三幕结构：2024 旧校官网 → 1989 校报编辑室 → 2024 表 / 里网页
- 档案登录、封印文件、终端密码、童谣线索、表里切换、6 件里页证据
- 收集证据并在推理板上合成（触屏点选两张 / 桌面拖拽）
- 自动存档、继续游戏、结局鉴赏（4 个结局）、提示系统、音效开关

## 特点

- 纯前端单机：无内购、无广告、无联网请求、不收集个人信息、不申请系统权限
- 离线可玩：断网后仍可完整通关；存档仅保存在本机浏览器
- 移动适配：竖屏优先，触控区域 ≥44px，支持刘海屏安全区

## 适龄提示

本作含死亡、失踪、灵异等文字描写（无血腥画面），建议 16 周岁以上玩家体验。故事纯属虚构，请勿模仿。

## 隐私

本游戏不收集任何个人信息。详见 [隐私说明](privacy.html)。

## 技术

单页 H5（HTML / CSS / JavaScript，无构建、无第三方依赖），支持 `file://` 离线打开。Android 版本由 WebView 离线包装，构建配置见仓库 `android/`。

## 项目结构

```
index.html        # 游戏入口
css/ js/ assets/  # 游戏静态资源
privacy.html      # 隐私说明
android/          # Android WebView 包装工程 + GitHub Actions APK 构建
```
